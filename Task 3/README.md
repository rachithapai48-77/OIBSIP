# Task 3 – Netflix Exploratory Data Analysis (EDA)

## Objective

The objective of this task was to perform Exploratory Data Analysis (EDA) on the Netflix titles dataset using Python and Pandas.

## Methodology

The following steps were performed:

1. Loaded the Netflix dataset.
2. Inspected the dataset shape, columns, data types, and missing values.
3. Generated summary statistics.
4. Analyzed the distribution of Movies and TV Shows.
5. Analyzed Netflix titles by release year.
6. Examined the correlation between numerical features.
7. Analyzed the number of titles added to Netflix by year.
8. Analyzed the distribution of content ratings.
9. Created visualizations to communicate the findings.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Dataset

The Netflix dataset contains information about Netflix movies and TV shows, including title, type, director, cast, country, date added, release year, rating, duration, genre, and description.

## Visualizations

The analysis includes visualizations for:

- Movies vs TV Shows
- Titles by Release Year
- Netflix Titles Added by Year
- Titles by Rating

## Output

The completed Jupyter Notebook and relevant visualization images are included in this folder.

## Conclusion

The Netflix dataset was successfully explored using Python and Pandas. The analysis provided insights into the distribution of content types, release years, titles added over time, and content ratings.
