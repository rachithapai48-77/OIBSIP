# Task 1 – Titanic Data Cleaning and Preprocessing

## Objective

The objective of this task was to perform data cleaning and preprocessing on the Titanic dataset using Python and Pandas.

## Methodology

The following steps were performed:

1. Loaded the Titanic dataset using Pandas.
2. Inspected the dataset structure and columns.
3. Checked for missing values.
4. Identified the data types of the columns.
5. Performed basic data cleaning and preprocessing.
6. Examined the cleaned dataset and its important features.

## Tools and Technologies

- Python
- Pandas
- Google Colab
- Jupyter Notebook

## Dataset

The Titanic dataset contains passenger information such as PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, and Embarked.
