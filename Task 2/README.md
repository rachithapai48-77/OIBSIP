# Task 2 – Iris Data Visualization

## Objective

The objective of this task was to explore and visualize the Iris dataset using Python and data visualization techniques.

## Methodology

The following steps were performed:

1. Loaded the Iris dataset.
2. Inspected the dataset structure and features.
3. Calculated summary statistics for the dataset.
4. Grouped the data by species and calculated average measurements.
5. Created visualizations to understand relationships between the Iris features.
6. Analyzed the patterns and differences among the three Iris species.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Dataset

The Iris dataset contains measurements of sepal length, sepal width, petal length, and petal width for three species: Setosa, Versicolor, and Virginica.

## Output

The completed analysis, source code, and relevant visualization screenshots are included in this folder.

## Conclusion

The Iris dataset was successfully analyzed and visualized. The visualizations helped identify differences in flower measurements among the three Iris species.
